# Distributed Data Analytics: Porto Taxi Trajectory

## Overview
This project focuses on extracting and analyzing urban mobility patterns from a large-scale geospatial dataset of taxi trajectories in Porto, Portugal. The database comprises **1.66 million trips and over 82.6 million GPS points**. 

## Tech Stack
* **Databases:** MySQL
* **Languages:** SQL, Python
* **Concepts:** Relational Database Schema, Spatial & Temporal Queries, Big Data Analytics

## Key Features & Queries
* **Geospatial Analysis:** Applied advanced SQL logic to evaluate spatial distributions, including filtering trips within specific bounding boxes (e.g., proximity to Porto City Hall).
* **Temporal Trends & Metrics:** Computed complex trip metrics such as average duration, distance per call type, and wait times between consecutive trips using window functions.
* **Python Integration:** Developed and executed all complex SQL queries programmatically via Python scripts to automate data retrieval and metric calculation.

## Documentation & Collaboration
This project was developed collaboratively within a cross-cultural academic team at NTNU. The repository includes the comprehensive project report detailing the database schema, data cleaning rules, and the results of the SQL queries. 

> *Note: The raw dataset is not included in this repository due to its large size (Big Data constraints), but the analytical queries and methodology are fully documented.*
